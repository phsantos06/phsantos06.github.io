# phsantos06.github.io

Portfólio de **Paulo Henrique** — desenvolvedor de software.

**Acesse:** https://phsantos06.github.io · https://phsantos06.vercel.app

Sites institucionais, sistemas web e estudos, apresentados com direção de movimento: scroll cinematográfico, revelações por máscara, cards empilhados e cursor personalizado — com suporte a `prefers-reduced-motion` e experiência pensada para celular.

## Stack
HTML · CSS · JavaScript · [GSAP](https://gsap.com) + ScrollTrigger · [Lenis](https://lenis.darkroom.engineering)

## Estrutura
```
index.html        # conteúdo
styles.css        # layout, tipografia e responsividade
main.js           # animações, menu mobile e cursor
assets/projetos/  # capas dos projetos
```
